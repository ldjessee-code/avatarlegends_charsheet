Install and run offline

Windows, Mac, and Linux — same idea. No installer. Browser only.

Have internet? Easiest option: Play online (GitHub Pages). Use the zip below when you want files on your computer with no network.

1. Get the folder

  1. Save AvatarLegends-charsheet-offline.zip from your GM.
  2. Unzip it:
    • Windows: Right-click → Extract All…
    • Mac: Double-click the zip
    • Linux: Right-click → Extract, or unzip …
  3. Confirm you see index.html and folders playbooks/, css/, js/, data/. Keep the whole folder together.

2. Open the sheets

  1. Open the unzipped folder.
  2. Double-click index.html (or a file under playbooks/).
  3. It opens in your browser. Bookmark if you like.

If the page looks unstyled, you opened a lone HTML file outside the folder — open index.html from the complete unzipped set.

3. Play offline

  • Edits autosave in that browser on that computer.
  • After every session: Download JSON and email the file to your GM (email backup + you’re both on the same page about the character).
  • Load JSON to restore a backup on a new device or after clearing browser data.

Updating

When you get a new zip, unzip to a new folder (or replace the old one), then Load JSON your latest backup if needed.
