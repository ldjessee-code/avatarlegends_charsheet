# Add to Home Screen (iPhone, iPad, Android)

You can put a shortcut icon on your home screen so the character sheets open like a simple app.  
This uses the **browser’s “Add to Home Screen”** feature — not a separate App Store install.

**Best on the live site (needs internet the first time you add it):**  
https://ldjessee-code.github.io/avatarlegends_charsheet/

Offline zip + home screen is awkward on phones (multi-file `file://` pages often break). Prefer **GitHub Pages** for mobile icons; use the **zip on a computer** for full offline.

---

## iPhone / iPad (Safari)

1. Open **Safari** (not Chrome for this step — Apple’s Add to Home Screen is most reliable in Safari).
2. Go to:  
   https://ldjessee-code.github.io/avatarlegends_charsheet/  
   or your playbook URL, e.g.  
   `…/playbooks/foundling.html`
3. Tap the **Share** button (square with an arrow pointing up).
4. Scroll the share sheet and tap **Add to Home Screen**.  
   - If you don’t see it: tap **Edit Actions** / **More** and enable it.
5. Edit the name if you want (e.g. “Avatar Sheet” or your character name).
6. Tap **Add**.

An icon appears on the home screen. Tapping it opens the sheets in a full-screen-style Safari window.

**Notes**

- Data is stored in Safari for that site (same as the browser).
- **After every session:** **Download JSON** and **email the file to your GM** (backup in email + shared character state).
- After a major site update, you may need to open the URL in Safari again; the home screen shortcut usually still works.

---

## Android (Chrome — equivalent of “Add to Home Screen”)

Yes — Android has the same idea:

1. Open **Chrome**.
2. Go to:  
   https://ldjessee-code.github.io/avatarlegends_charsheet/
3. Tap the **⋮** menu (three dots, top right).
4. Tap **Add to Home screen** or **Install app** / **Install page**  
   (wording varies by Chrome version; both create a home screen icon).
5. Confirm **Add**.

Other Android browsers (Firefox, Edge, Samsung Internet) usually have a similar menu item: **Install**, **Add to Home screen**, or **Add to phone**.

**Notes**

- Same origin storage as Chrome for that site.
- **After every session:** **Download JSON** and **email the file to your GM**.

---

## Windows / Mac desktop “icon”

- **Bookmark** the hub or playbook tab (simplest).
- **Chrome/Edge:** menu → **Cast, save, and share** / **More tools** → **Create shortcut** (optional “Open as window”).
- **Mac Safari:** File → Add to Dock (version-dependent) or drag the URL from the address bar to the Desktop/Dock.

Desktop shortcuts are optional; double-clicking `index.html` from the offline folder is enough on a PC.
