Accessibility statement

Unofficial fan project for Avatar Legends character sheets (static HTML/CSS/JS). Not affiliated with Magpie Games or Viacom/Paramount.

Goals

  • Screen reader users (VoiceOver, TalkBack, NVDA, JAWS)
  • Keyboard-only and limited-mobility users
  • Reduced motion / clearer structure
  • Large text, zoom, and mobile browsers

Accessibility work should improve structure, names, and keyboard behavior without redesigning the visual theme unless contrast or size fails basic readability.

Character JSON format

Download JSON produces a portable character file. Prefer this for backups, email to the GM, and automation.

Top-level shape (v3+)

{
  "_meta": { },
  "character": { },
  "images": { }
}

Images (base64 data-URLs) live under images at the end so the rest stays readable. Older files may still have inline images; Load JSON accepts both.

Version

versionNotes
2Meta URLs; images often inline
3Top-level images block

Session playDate is the user’s local calendar date (YYYY-MM-DD), not UTC midnight.

AI & automation

Prefer structured JSON and documented actions over vision-based UI clicking or fragile CSS selectors.

Today

  • Export / import character JSON (versioned contract)
  • Stable playbook URLs under /playbooks/<id>.html
  • No public HTTP API on GitHub Pages

Conceptual verbs

Helpers should think in operations such as load_character, export_character, set_fatigue, toggle_condition, add_session_note — implemented later as UI commands or local tools, not system App Intents.

Out of scope for now

Native iOS App Intents / Android App Actions. A Swift app can reuse the same JSON later if needed.
