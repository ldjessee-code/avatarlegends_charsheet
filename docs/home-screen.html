Add to Home Screen

Put a shortcut on your phone or tablet home screen so the sheets open like a simple app. This is a browser feature — not an App Store install.

Use the live website for home screen icons (GitHub Pages). Offline zip folders work best on a computer; multi-file pages on a phone often break when opened from Files.

iPhone / iPad (Safari)

  1. Open Safari.
  2. Go to the character sheet hub (or your playbook page).
  3. Tap Share (square with ↑).
  4. Tap Add to Home Screen (may be under Edit Actions / More).
  5. Name it (e.g. “Avatar Sheet”) → Add.

Still use Download JSON for backups and sending to the GM.

Android (Chrome) — yes, same idea

  1. Open Chrome.
  2. Go to the character sheet hub.
  3. Tap ⋮ (three dots).
  4. Tap Add to Home screen or Install app / Install page (wording varies).
  5. Confirm Add.

Firefox, Edge, and Samsung Internet usually have a similar menu item (“Install”, “Add to Home screen”, or “Add to phone”).

Computer shortcut (optional)

  • Bookmark the hub or playbook tab.
  • Chrome/Edge: create a shortcut / “Open as window” from the browser menu.
  • Or use the offline folder and double-click index.html — see Install offline.
