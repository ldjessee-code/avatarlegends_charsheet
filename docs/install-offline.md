# Install and run offline (Windows, Mac, Linux)

No installer, no app store, no internet required after you have the files.

## What you need

- A desktop or laptop browser: **Chrome**, **Firefox**, **Edge**, or **Safari**
- The offline zip from your GM (or a clone of this project)

Online play (recommended when you have internet):  
https://ldjessee-code.github.io/avatarlegends_charsheet/

## Steps (same idea on every computer)

### 1. Get the folder

1. Save the file **`AvatarLegends-charsheet-offline.zip`** (your GM emails this).
2. **Unzip** it:
   - **Windows:** Right-click the zip → **Extract All…** → choose a folder → Extract.  
     Or double-click the zip and drag the contents into a new folder.
   - **Mac:** Double-click the zip; a folder appears next to it.
   - **Linux:** Right-click → Extract, or `unzip AvatarLegends-charsheet-offline.zip`
3. You should see **`index.html`**, plus folders like `playbooks/`, `css/`, `js/`, `data/`.  
   **Keep that whole folder together** — don’t move only one HTML file.

### 2. Open the sheets

1. Open the unzipped folder.
2. Double-click **`index.html`**  
   — or open your playbook, e.g. `playbooks/adamant.html`.
3. It opens in your default browser. You can bookmark that tab.

**Tip:** If styles look missing, you opened a file outside the folder or only copied one HTML file. Open `index.html` from inside the complete unzipped folder.

### 3. Use offline

- Character data **autosaves in that browser** on that device.
- **After every session:** **Download JSON** and **email the file to your GM**.  
  That keeps a backup in email and keeps you both on the same page about the character.  
  (Works offline; send the mail when you next have connectivity.)
- **Load JSON** restores a backup on a new device or after clearing browser data.

No server, no “install package.” It’s just files + a browser.

## Optional: always open with a specific browser

- **Windows:** Right-click `index.html` → Open with → choose Chrome/Edge/Firefox (check “Always”).
- **Mac:** Right-click → Open With → choose browser, or drag the file onto the browser icon in the Dock.

## Updating

When the GM sends a **new zip**, unzip to a **new folder** (or replace the old one).  
Then **Load JSON** your last backup if the browser storage was cleared or you switched folders/browsers.
