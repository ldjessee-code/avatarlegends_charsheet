Advanced options

Online play is the default. You can also run fully offline on a computer, or pin a home-screen icon on a phone or tablet.

Offline

Install locally (no internet)

Windows · Mac · Linux

Unzip the offline pack from your GM, open index.html in a browser. No install wizard.

Mobile

Home screen icon

iPhone · iPad · Android

Add to Home Screen (Safari on Apple, Chrome on Android) so the sheets open like an app icon.
