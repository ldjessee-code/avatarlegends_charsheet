Avatar Legends

Digital HTML/CSS/JS character sheets for Powered by the Apocalypse playbooks from the Core Book and Wan Shi Tong’s Adventure Guide.

Example ready for review: The Adamant

Open The Adamant below. Character name is primary in the header; playbook is secondary on the right. Collapsible sections (history, growth, sessions…), training-based color themes, portrait image, and Save to file / Load from file (plus browser auto-save). Start here if you only opened a playbook page before — this is the playbook picker.
